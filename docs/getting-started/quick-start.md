# WP Plugin Starter Quick Start Guide

> **Documentation Version**: This documentation is based on WP Plugin Starter version 1.0.0. Features and functionality may vary in other versions.

This quick start guide will help you get WP Plugin Starter up and running on your WordPress site quickly and efficiently.

## 🚀 Before You Begin

Ensure your system meets the following requirements:

- WordPress 6.4.2 or higher
- PHP 7.4 or higher
- WP Plugin Starter Lite 3.9.7 or higher
- WooCommerce 7.9 or higher

If you haven't already installed WP Plugin Starter, please follow the [Installation Guide](installation.md).

## ⚡ Quick Setup Steps

### Step 1: Activate WP Plugin Starter

1. Navigate to **Plugins > Installed Plugins** in your WordPress admin
2. Find "WP Plugin Starter" in the list
3. Click **Activate**

### Step 2: Access the WP Plugin Starter Dashboard

1. Navigate to **WP Plugin Starter** in your WordPress admin sidebar
2. You'll see the main WP Plugin Starter dashboard with feature cards and statistics

### Step 3: Configure Essential Settings

1. Navigate to **WP Plugin Starter > Settings** in the sidebar
2. Configure the following essential settings:

   **General Settings:**
   - **License Key**: Enter your license key (if applicable)
   - **Feature Activation**: Enable the core features you plan to use
   - **Admin Email**: Configure notification emails for administrative alerts

   **Vendor Settings:**
   - **Vendor Registration**: Configure the registration process
   - **Vendor Capabilities**: Set basic vendor permissions
   - **Commission Structure**: Set your default commission rates

### Step 4: Enable and Configure Key Features

#### Product Management

1. Navigate to **WP Plugin Starter > Settings > Product**
2. Configure these key settings:
   - Enable product types you want vendors to use
   - Set up basic image restrictions (if needed)
   - Configure essential product fields

#### Shipping

1. Navigate to **WP Plugin Starter > Settings > Shipping**
2. Configure basic shipping settings:
   - Enable shipping methods
   - Set up default shipping zones
   - Configure how vendors manage shipping

#### Checkout

1. Navigate to **WP Plugin Starter > Settings > Checkout**
2. Configure essential checkout options:
   - Optimize the checkout process
   - Configure multi-vendor cart behavior
   - Set up default thank you page messages

### Step 5: Test Your Configuration

Test the basic setup to ensure everything is working correctly:

1. Create a test vendor account
2. Add a test product as a vendor
3. Make a test purchase to verify checkout flow
4. Verify commission calculations
5. Test the order processing workflow

## 🛠 Feature-Specific Quick Setup

### Vendor Levels (Optional)

If you want to set up vendor levels:

1. Navigate to **WP Plugin Starter > Vendor Levels**
2. Click **Add New Level**
3. Configure the level with:
   - Level name and description
   - Commission structure
   - Feature access
   - Qualification criteria
4. Click **Save Level**
5. Assign vendors to levels manually or set up automatic assignment rules

### Advanced Product Options (Optional)

To enhance product management:

1. Navigate to **WP Plugin Starter > Settings > Product > Advanced**
2. Configure these features:
   - Product templates
   - Custom fields
   - Bulk editing capabilities
   - Product import/export settings

### Enhanced Shipping (Optional)

For advanced shipping features:

1. Navigate to **WP Plugin Starter > Settings > Shipping > Advanced**
2. Set up:
   - Distance-based shipping
   - Table rate shipping
   - Shipping label integration
   - Delivery time options

### Checkout Optimization (Optional)

To enhance the checkout experience:

1. Navigate to **WP Plugin Starter > Settings > Checkout > Optimization**
2. Configure:
   - One-page checkout
   - Field optimization
   - Buy now functionality
   - Abandoned cart recovery

## 🔍 Troubleshooting First-Time Setup

### Common Issues

- **Settings Not Saving**: Clear browser cache and cookies
- **Features Not Appearing**: Check feature activation and permissions
- **Vendor Dashboard Errors**: Verify WP Plugin Starter compatibility and theme conflicts
- **Email Not Sending**: Check email settings and server configuration
- **Payment Issues**: Verify payment gateway settings and currencies
