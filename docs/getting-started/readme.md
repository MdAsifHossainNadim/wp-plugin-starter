## System Requirements Overview

Before installing Dokan Kits, ensure your system meets these requirements:

- WordPress: 6.4.2 or higher
- PHP: 7.4 or higher
- WooCommerce: 7.9 or higher
- Dokan Lite/Pro: 3.9.7 or higher
- MySQL: 5.7+ or MariaDB 10.2+
- WordPress memory limit: 128MB or higher recommended

For detailed server requirements and configuration recommendations, see the [Requirements](requirements.md) page.

## Installation Steps

1. **Plugin Installation**:
   - Upload the plugin via WordPress admin or FTP
   - Activate through the WordPress plugins page

2. **Dependency Verification**:
   - Ensure WooCommerce and Dokan are installed and activated
   - Check version compatibility with your system

3. **Initial Setup**:
   - Configure basic settings via the Dokan Kits dashboard
   - Enable/disable specific features as needed

For detailed installation instructions, see the [Installation](installation.md) guide.
